## 仓库里有什么

| 文件 | 作用 |
|---|---|
| `README.md` | 就是你现在读的这个文件，项目的「说明书」，GitHub 会自动显示在仓库首页 |
| `index.html` | 一个网页，会通过 GitHub Pages 发布成可访问的网址 |

## 三分钟上手：动手改一个字

1. 在仓库页面点开 `README.md`
2. 点右上角的 **铅笔图标**（Edit this file）
3. 在下面的编辑框里随便改一句，比如把这一行改成「这是我改的第一句话」
4. 滚到底部，点绿色按钮 **Commit changes**
5. 回到仓库首页刷新 —— 改动就出现在上面了，而且**历史记录里永远保留着旧版本**

> 这就是 GitHub 和网盘最大的区别：每次改动都有记录，改错了可以回退。

## 名词速查表

| 名词 | 人话 |
|---|---|
| Repository 仓库 | 一个项目，包含文件 + 全部修改历史 |
| Star 星标 | 收藏书签，等于「点赞 + 稍后再看」 |
| Fork 派生 | 把别人的仓库复制一份到自己账号下 |
| Commit 提交 | 一次「保存并记录」，会写进历史 |
| Issue 议题 | 项目的问题留言板 |
| Pull Request | 你改了代码，申请合并回原项目 |
| GitHub Pages | 把仓库变成免费网站的功能 |
